   # Домашка Homework
   ## Цель домашки
Работа предоставляет возможность для обработки и маскировки банковских данных, фильтрации и сортировки операций
   ## Используемые инструменты для проверки оформления кода
Flake8 — проверка стиля кода.
Black — форматирование кода.
Isort — сортировка импортов.

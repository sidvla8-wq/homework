   # Домашка Homework
   ## Цель домашки
Работа предоставляет возможность для обработки и маскировки банковских данных, фильтрации и сортировки операций
   ## Используемые инструменты для проверки оформления кода
Flake8 — проверка стиля кода.
Black — форматирование кода.
Isort — сортировка импортов.
  ## Установка
Копируем репозиторий
git clone https://github.com/sidvla8-wq/homework.git

Вызвать команду: 
poetry add --group dev pytest 
для тестирования модулей программы через фремворк pytest

poetry add --group dev pytest-cov
устанавливаем данный пакет для проверки какой процент кода был протестирован

  ## Модуль test_masks.py 
Модуль test_masks.py - тестирует функции внутри модуля masks.py находящегося в пакете src

  ## Модуль test_widget.py 
Модуль test_widget.py - тестирует функции внутри модуля widget.py находящегося в пакете src

  ## Модуль test_processing.py 
Модуль test_processing.py - тестирует функции внутри модуля processing.py находящегося в пакете src

  ## Запуск тестов
Для проверки коррекности написания функций необходимо выполнить следующие команды:
pytest - автоматически найдет директорию tests и запустит все файлы, начинающиеся с test_ pytest сообщает, сколько тестов он нашел, и их состояние

Или переходим в любой модуль и нажимаем на зеленый трегольник рядом с фнкцией

  ## Процент протестированнного кода
В этой домашке процент протестированного кода составляет 93%
